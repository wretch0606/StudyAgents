# 一周冲刺计划

## 集成门

- 第 2 天：上传样例后可查询状态，并得到带页码的 `SourceRef`。
- 第 4 天：完成至少 3 题训练，返回分项评分、讲解和错题记录。
- 第 6 天：核心指标达标或形成明确缺陷清单，高风险安全缺陷为零。

集成门未通过时，次日先修复主链路，不增加新功能。第 7 天只允许修复阻塞性问题。

## 每日验收

### 第 1 天：定范围、定接口、搭骨架

- A：锁定 MVP，建立任务板、样例资料和评测框架。
- B：验证数字 PDF 解析和基础 OCR。
- C：定义 `AgentState`、公共 Schema 和公开事件。
- D：建立数据库、API、Worker 与部署骨架。
- E：用 Mock 完成登录、上传、问答和训练页面骨架。

### 第 2 天：资料可导入、可检索

- 完成上传、任务状态、切块、基础检索和页码引用。

### 第 3 天：可信问答闭环

- 完成引用核验、严格拒答、会话、运行、SSE 和 Agent 抽屉。

### 第 4 天：训练评分闭环

- 完成出题、作答恢复、评分、错题和掌握度。

### 第 5 天：全链路集成

- 跑通“登录 → 上传 → 问答 → 训练 → 错题”。
- 扫描答案泄露，补权限、幂等、恢复和响应式适配。

### 第 6 天：评测与集中修复

- 双人标注 50 条评测，计算 Recall、回答、引用、拒答和评分指标。
- 测试安全、性能、备份、E2E 和关键错误路径。

### 第 7 天：冻结与答辩

- 冻结资料和索引，完成 Compose 与恢复演练。
- 连续 3 次跑通完整演示；同时准备明确标记的演示缓存。
