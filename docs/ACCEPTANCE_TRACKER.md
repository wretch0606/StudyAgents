## 更新规则

- A 在每次集成门结束后更新本文件，并在 Issue #6 留下结果链接。
- `阻塞` 或 `失败` 必须记录复现步骤、影响、负责人和修复期限。
- 未通过集成门时，次日先修复主链路，不新增功能。
- 需求、契约或验收口径变化必须关联 Issue 或 `docs/adr/` 中的 ADR。
- 第 7 天只允许修复阻塞演示或高风险安全问题。
