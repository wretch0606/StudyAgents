## 一、检索接口

### 1.1 调用方式

```python
# 方式 1：直接调用（Agent 内）
from worker.retrieval.retriever import HybridRetriever

result = await retriever.retrieve(
    query="杨氏双缝干涉的条纹间距公式是什么？",
    query_embedding=None,         # 可选，传 None 使用降级向量
    filters=RetrievalFilters(
        chapter_ids=["ch-03"],
        question_types=None,      # 不限题型
        difficulty=None,          # 不限难度
        exclude_chunk_ids=[],     # 排除已用块
        knowledge_point_ids=[],
        year=None,
    ),
    user_role="member",           # "member" | "admin"
)
```

### 1.2 返回结构

```json
{
  "source_refs": [
    {
      "document_id": "uuid-of-document",
      "document_name": "光学讲义.pdf",
      "page_number": 12,
      "question_no": null,
      "chunk_id": "uuid-of-chunk",
      "excerpt": "两列光波在空间相遇时，若满足相干条件，则会产生干涉现象...",
      "page_image_url": "/api/documents/uuid/pages/12/image",
      "score": 0.0321
    }
  ],
  "sufficient": true,
  "reason": "sufficient",
  "requires_vision": false,
  "elapsed_ms": 320.5
}
```

### 1.3 `reason` 枚举与 C 的处理

| reason | 含义 | C 应如何处理 |
|---|---|---|
| `sufficient` | 证据充足 | 进入回答节点，组织答案 |
| `no_results` | 无匹配 | 拒答：说明知识库中未找到相关内容 |
| `topic_mismatch` | 主题不匹配 | 拒答：建议换个问法或补充资料 |
| `missing_condition` | 缺计算条件 | 拒答：说明缺少哪些数值/条件 |
| `conflicting` | 多来源矛盾 | 拒答：建议人工核验 |
| `staff_only` | 仅命中私有块 | 拒答：不向学生暴露受限内容 |
| `image_unavailable` | 需看图但页图不可用 | 拒答：说明图表暂时无法展示 |

## 二、SourceRef 字段说明

| 字段 | 类型 | 必填 | 用途 |
|---|---|---|---|
| `document_id` | string (UUID) | ✅ | 文档唯一标识，用于获取页图 |
| `document_name` | string | ✅ | 文档展示名，C 在回答中引用 |
| `page_number` | int | ✅ | 页码（从 1 开始），回答中展示 |
| `question_no` | string \| null | | 题号，真题为空时填 `null` |
| `chunk_id` | string (UUID) | ✅ | 块 ID，C 用于去重 |
| `excerpt` | string | ✅ | 摘录 ≤ 300 字，给 Agent 做上下文 |
| `page_image_url` | string \| null | | 页图地址，含图题时传给视觉模型 |
| `score` | float | | RRF 分数，C 可用于排序/过滤 |

### C 引用格式建议

```
[光学讲义.pdf 第12页] 两列光波在空间相遇时...
[2024年真题 第3题] 在杨氏双缝实验中...
```

## 三、RetrievalFilters 字段说明

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `chapter_ids` | `list[str]` | `[]` | 限定章节，空=不限 |
| `question_types` | `list[str] \| null` | `null` | `choice` / `fill_blank` / `calculation` / `short_answer` |
| `difficulty` | `int \| null` | `null` | 1-3，null=不限 |
| `exclude_chunk_ids` | `list[str]` | `[]` | 排除已用块，避免重复出题 |
| `knowledge_point_ids` | `list[str]` | `[]` | 限定知识点 |
| `year` | `int \| null` | `null` | 限定真题年份 |

## 四、真题候选（训练模式）

B 在数据库中维护 `exam_questions` 表。C 通过检索接口获取候选真题：

```python
# 获取计算类真题候选（难度 2，第 3 章）
result = await retriever.retrieve(
    query="",  # 空查询 = 不过滤关键词
    filters=RetrievalFilters(
        chapter_ids=["ch-03"],
        question_types=["calculation"],
        difficulty=2,
    ),
    user_role="admin",  # admin 可访问答案块
)
```

> ⚠️ 出题 Agent 必须使用 `user_role="admin"` 才能获取含答案的块。  
> 向学生展示的题目对象（PublicQuestion）**不得**包含 `answer_private` 和 `rubric_private`。

## 五、公开题目结构（C → E）

C 生成题目后，通过 D 的 API 传给前端。公开题目字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `item_id` | string | 题目唯一 ID |
| `order_no` | int | 序号（1-N） |
| `source_kind` | string | `past_exam`（真题）或 `generated_variant`（变式） |
| `question_type` | string | `choice` / `fill_blank` / `calculation` / `short_answer` |
| `difficulty` | int | 1-3 |
| `stem` | string | 题干，LaTeX 用 `$...$` 或 `$$...$$` |
| `options` | list | 选择题选项 |
| `source_label` | string | 展示用，如 "2024 年真题，第 3 题" |
| `progress` | dict | `{"current": 2, "total": 5}` |

### 严格禁止

| 禁止项 | 原因 |
|---|---|
| 公开题目含 `expected_answer` | 答案泄露 |
| 公开题目含 `rubric` | 评分点泄露 |
| 公开题目含 `private_content` | 私有块泄露 |
| SSE 事件含答案文本 | 前端抓包泄露 |
| 日志含 `answer_private` | 日志可能被导出 |

## 六、SSE 事件格式

B 通过 D 的 SSE 推送 Agent 步骤摘要。C 负责在每个节点完成后写入事件：

```json
{
  "id": "evt-001",
  "run_id": "run-uuid",
  "sequence_no": 1,
  "agent": "knowledge",
  "event_type": "agent.summary",
  "status": "succeeded",
  "summary": "知识 Agent 在第 3 章找到 6 条可引用证据",
  "source_refs": [...],
  "duration_ms": 320,
  "created_at": "2026-07-23T10:30:00Z"
}
```

**字段说明：**

| 字段 | 说明 |
|---|---|
| `agent` | `coordinator` / `knowledge` / `questioner` / `evaluator` / `system` |
| `event_type` | `run.started` / `agent.started` / `agent.summary` / `agent.completed` / `run.waiting_user` / `run.completed` / `run.failed` / `heartbeat` |
| `status` | `queued` / `running` / `waiting_user` / `succeeded` / `failed` |
| `summary` | 中文公开摘要，**不暴露**私有答案、评分点、原始数据库查询 |
